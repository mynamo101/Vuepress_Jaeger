::: tip 給新手的話
第一次聽到 Wwise 嗎？別緊張！我也是從完全不懂開始的。想像一下你在玩遊戲時，那些讓你雞皮疙瘩的背景音樂、嚇得你跳起來的突然音效，還有走在不同地面上腳步聲的變化 - 這些魔法般的音效體驗，很多都是用 Wwise 做出來的！
:::

## 所以 Wwise 到底是什麼？

簡單來說，Wwise 就是一個讓你的遊戲「有聲有色」的超強工具！

還記得小時候玩遊戲時，那種音效和畫面完美配合的震撼感嗎？Wwise 就是創造這種體驗的幕後功臣。它不只是播放音效那麼簡單，更像是一個聰明的音效導演，會根據遊戲情況自動調整音樂和音效。

### 為什麼大家都愛用 Wwise？
- 🎵 **智慧音樂系統** - 會看心情換歌的音樂播放器（緊張時播緊張的，放鬆時播輕鬆的）
- 🔊 **超真實 3D 音效** - 聲音會從正確的方向傳來，就像現實世界一樣
- 🎛️ **即時調音台** - 遊戲進行中還能調整音量和效果
- 🚀 **到處都能用** - 手機、電腦、遊戲機都支援
- 🔧 **和遊戲引擎當好朋友** - Unity 和 Unreal 都能無縫整合

## 開始前的準備工作

別急著下載，先檢查一下你的電腦夠不夠力！

### 你的電腦至少要有這些配備
- **作業系統**: Windows 10（越新越好，老電腦可能會有些小問題）
- **記憶體**: 4 GB（但說真的，8 GB 會讓你舒服很多）
- **硬碟空間**: 2 GB（不算多，但記得清一下垃圾檔案）
- **處理器**: i5 等級就夠了（不用擔心，現在的電腦通常都比這強）

### 如果你想要更順暢的體驗
- **記憶體**: 16 GB（相信我，多一點記憶體真的差很多）
- **硬碟空間**: 5 GB（包含一些很棒的範例專案）
- **顯卡**: 有獨立顯卡更好（但內建的也行）

::: warning 老實說...
我當初用 4 GB 記憶體跑 Wwise，那個卡頓感真的很痛苦。如果預算允許，真心建議升級到 8 GB 以上，你會感謝我的！
:::

## 好了，開始下載和安裝吧！

### 第一步：去官網拿軟體

別擔心，不會很複雜的！

1. 打開瀏覽器，前往 [Audiokinetic 官方網站](https://www.audiokinetic.com/download/)
2. 還沒帳號的話就註冊一個（免費的，不用錢！）
3. 登入後找到大大的 **"Download Wwise"** 按鈕，點下去
4. 版本選擇的小撇步：
   - 看到 **LTS（長期支援）** 就選它！比較穩定，適合新手
   - **Release** 是最新版，功能多但可能有小 bug

::: tip 我的經驗談
第一次用 Wwise 時，我就是貪新選了 Release 版本，結果遇到一些莫名其妙的問題。後來改用 LTS 版本，世界瞬間清淨了！新手真的建議選 LTS。
:::

### 第二步：安裝這個大傢伙

1. **找到下載檔案**
   - 檔名通常是 `Wwise_v20XX.X.X_Setup.exe`
   - 一定要「右鍵 → 以系統管理員身分執行」（這很重要！）

2. **選擇安裝方式**
   - 有選項的話就選 **"Complete Installation"**
   - 雖然會大一點，但包山包海，省得以後麻煩

3. **安裝位置**
   ```
   預設路徑：C:\Program Files (x86)\Audiokinetic\Wwise 20XX.X.X\
   ```
   - 除非你有特殊需求，不然就用預設路徑吧
   - 自訂路徑有時候會造成一些奇怪的問題

### 第三步：選擇要安裝的東西

這裡會跳出一堆選項，看起來很複雜，但其實不難：

#### 一定要裝的（不選會後悔）
- ✅ **Wwise** - 這是主程式，當然要選
- ✅ **Wwise SDK** - 開發必備，沒有這個就像買車沒有引擎
- ✅ **Documentation** - 說明書，卡關時的救星

#### 看你要做什麼平台（按需選擇）
- ✅ **Windows** - 做 PC 遊戲必選
- ⬜ **iOS** - 要做手機遊戲再選
- ⬜ **Android** - 同上
- ⬜ **Nintendo Switch** - 這個需要特殊授權，一般人用不到

#### 整合工具（超重要！）
- ✅ **Unity Integration** - 用 Unity 的一定要選
- ✅ **Unreal Integration** - 用 Unreal 的一定要選

#### 學習用的好東西
- ✅ **Sample Projects** - 範例專案，學習神器
- ✅ **Cube Demo** - 簡單的互動示範，適合入門

::: warning 血淋淋的教訓
我第一次安裝時，想說節省空間就沒選範例專案，結果學習時找不到參考，又要重新下載安裝。相信我，硬碟空間值得為了學習效率犧牲！
:::

### 第四步：等待安裝完成

1. 所有選項都確認後，點 **"Install"**
2. 去泡杯咖啡或茶，大概要等 5-15 分鐘
3. 看到安裝完成，記得勾選 **"Launch Wwise"** 馬上啟動來玩玩看

## 第一次啟動 - 不要緊張！

### 授權設定（免費的那種）

第一次打開會問你要用哪種授權：

1. **Non-Commercial（非商業）** - 選這個！免費的
   - 學習用、個人專案、小團隊都可以用
   - 只要年收入不超過 $150,000 美金就能免費使用

2. **Commercial（商業）** - 要花錢的，除非你是大公司

接著輸入你的帳號密碼，系統會自動搞定授權。

### 選個專案來玩玩

啟動後會看到專案選擇畫面：
- **新手建議先玩 "Cube Demo"** - 簡單易懂，可以馬上聽到效果
- **想從零開始可以選 "Empty Project"** - 空白專案，自由發揮

::: tip 給完全新手的建議
我強烈建議先玩 Cube Demo！雖然看起來很簡單，但你可以在 5 分鐘內就體驗到 Wwise 的神奇之處。那種第一次聽到 3D 音效的震撼，真的會讓你愛上音效設計！
:::

## 確認一切都裝好了

### 簡單測試一下

1. **檢查主介面**
   - 打開後應該看到滿滿的面板和選項
   - 如果看起來很亂很複雜，恭喜你！這就對了

2. **試試音效播放**
   - 載入範例專案
   - 隨便點個音效播放，聽得到聲音就 OK

3. **檢查 SDK 資料夾**
   ```
   SDK 通常在這裡：
   C:\Program Files (x86)\Audiokinetic\Wwise 20XX.X.X\SDK\
   ```

### 如果遇到問題怎麼辦？

#### 安裝失敗了？
- 檢查一下是不是忘記用「系統管理員身分執行」
- 防毒軟體有時候會搗亂，試著暫時關閉
- 硬碟空間不夠也會出問題

#### 裝好了但打不開？
- Windows 更新一下試試
- 可能缺少 Visual C++ 套件，去微軟官網下載
- 重新安裝 DirectX

#### 授權有問題？
- 確認網路連線正常
- 檢查防火牆是不是太嚴格
- 真的不行就寫信給 Audiokinetic 客服（他們人很好的）

恭喜你成功踏入 Wwise 的世界！🎉

1. 📚 **先別急著做專案** - 花點時間了解基本概念，磨刀不誤砍柴工
2. 🎮 **好好玩玩範例專案** - 看看別人是怎麼做的，偷師學藝
3. 🔧 **連接到你的遊戲引擎** - Unity 或 Unreal 的整合設定
4. 🎵 **開始你的第一個音效** - 從簡單的開始，不要好高騖遠
