# Wwise 入門課程導覽

這一系列課程從「最小可行」到「實務整合」，循序建立你的 Wwise 心智模型。建議依序閱讀，並在每一節做最小實作驗證。

## 課程地圖
1. 建立第一個專案
2. Event 與最小可行播放
3. Actor-Mixer 層級與分類策略
4. Bus 與混音基礎
5. Random Container 入門
6. Switch Container 入門
7. RTPC 動態控制
8. Blend Container 連續過渡
9. 3D 定位與衰減
10. 效果與 Reverb Send 基礎
11. Ducking 與優先層級
12. 綜合實戰：小型互動場景
13. State 與 Switch 差異與應用
14. 語音與本地化流程
15. SoundBank 管理與平台策略
16. 效能與資源管理
17. Profiler 與 Debug 工具

## 使用方式
- 每章末尾的「檢查清單」= 你是否真正吸收的驗證
- 若卡住 → 回到上一章確認前置是否完成
- 可在 Git / 任務管理工具中紀錄每章完成日期與心得

## 推薦配套練習
| 章節 | 小挑戰 |
| ---- | ------ |
| Event | 自己命名 5 個語意事件 |
| Random | 腳步 + UI 點擊加自然變化 |
| Switch | 加入至少 4 種材質腳步 |
| RTPC | 速度驅動腳步 Pitch |
| Blend | 簡單 3 層引擎過渡 |
| 3D | 做一個可接近遠離的火焰 |
