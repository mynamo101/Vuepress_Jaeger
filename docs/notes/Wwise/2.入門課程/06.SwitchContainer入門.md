::: tip 🔀 讓聲音根據「條件」正確變身
Random 解決「同類多變化」，但當邏輯是：依『狀態 / 條件』選擇『唯一分支』時，Switch Container 就是你的武器。地面材質、武器類型、角色形態……都屬於「條件決策」而不是純隨機。
:::

## 🎯 本節你會收穫
- 🧭 迅速理解 Switch 與 Random 的核心差異
- 🧱 建立一個地面材質腳步切換系統的完整流程
- 🔗 清楚知道程式端必須送哪些資料（SetSwitch / PostEvent）
- 🛡️ 設計預設值與防呆（Fallback）策略
- 🧬 與 Random Container 組合的常見結構模式
- 🧪 測試、驗證與常見失敗案例排查

## 🧠 核心概念速記
| 類型 | 運作方式 | 適合情境 | 例子 |
| ---- | -------- | -------- | ---- |
| Random | 從一組樣本隨機抽取（可加權 / 避免重複） | 同質類變化 | 腳步單一材質變化、環境細碎聲 |
| Switch | 根據當前條件值，指向唯一分支 | 條件決策 / 狀態分支 | 地面材質、武器、角色姿態 |

一句話：Random =「這一類裡換著玩」；Switch =「現在是哪一種？」。

## 🛠️ 建立地面材質腳步系統（步驟）
1. Switch Group：Project Explorer → Switches → New → `SurfaceType`
2. 建立值：`Grass` / `Stone` / `Wood` / `Metal`（命名用 PascalCase 或統一規則）
3. 建立 Switch Container：命名 `Footstep_By_Surface`
4. 在其下為每個分支放一個 Random Container（每個 4~6 個腳步樣本）
5. 建立 Event：`Play_Footstep` 指向 `Footstep_By_Surface`
6. 生成 SoundBank 測試（別忘了更新）

### 結構示例
```
Footstep_By_Surface (Switch)
  ├─ Grass (Random 5 個)
  ├─ Stone (Random 5 個)
  ├─ Wood  (Random 5 個)
  └─ Metal (Random 5 個)
```

### 為何每個分支再套 Random？
避免同材質內部重複；Switch 決策材質 → Random 提供微變化，兩者職責清楚不混用。

## 🔗 遊戲端需要提供的資訊
| 動作 | 程式需呼叫 | 時機 |
| ---- | ---------- | ---- |
| 角色進入新地面 | `SetSwitch(SurfaceType, Grass)` | 探測碰撞 / 地面貼圖改變 |
| 播放腳步 | `PostEvent(Play_Footstep, Player)` | 動畫事件 / 移動節奏 |

### 命名建議
Switch Group 用語意泛化（SurfaceType），值用語義單詞（Grass / Stone）。避免 `Grass1` 這種後期難維護命名。

## 🛡️ 預設值 / 防呆策略
若程式忘了或延遲送 Switch：
- 設定一個 Default 值（最常見材質，如 Grass）
- 或建立一個 Neutral / Fallback 分支（音色中性、可通用）
- 可在測試期加 Log：當長時間未收到 SetSwitch 仍播放 Default，標記供工程修正

## 🧬 常見結構模式（實務）
| 模式 | 結構 | 使用時機 |
| ---- | ---- | -------- |
| 單層 Switch+Random | Switch → Random | 基礎腳步 / 武器揮擊 |
| Switch + 子分類 | Switch → Random(Soft/Hard) | 同材質再分不同力度 |
| Switch + RTPC | Switch → Random → RTPC Pitch | 速度影響腳步高度感 |

## 🚨 常見錯誤與避坑
| 問題 | 根因 | 解法 |
| ---- | ---- | ---- |
| 聽起來仍重複 | 分支內部沒 Random | 每分支最少 4 個樣本 + 適度差異 |
| 播放錯材質 | SetSwitch 時機晚於腳步 Event | 動畫 Footstep 通知前即設 Switch |
| 預設一直被用 | 程式漏發或地面判定失效 | 加 Debug 記錄未切換次數 |
| 分支爆炸增長 | 把輕 / 重 / 滑動都做成獨立 Switch 值 | 改：材質用 Switch，力度用 Random 或 RTPC |

## 🧪 測試流程（Soundcaster）
1. 加入 `Play_Footstep` 事件
2. 在 Switch 面板逐一切換 SurfaceType
3. 每材質連續播放 10~15 次聽是否有重複感（若有 → 增樣本或調權重）
4. 強制不 SetSwitch（僅播放）驗證 Default 行為
5. 與角色動畫節奏對齊（若 Pitch 或時間感不符 → 之後 RTPC 可微調）

## 🔍 Debug 速查
| 症狀 | 檢查點 |
| ---- | ------ |
| 沒聲音 | Event 是否指到 Switch Container / Bank 更新 | 
| 永遠同材質 | 程式是否固定送同一值 / 沒更新偵測 | 
| 延遲一腳才切換 | SetSwitch 呼叫發生在上一幀腳步後 |
