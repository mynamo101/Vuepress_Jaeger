::: tip 🌫️ 讓聲音「進空間」，而不是漂浮在耳邊
Reverb / 空間效果若使用不當會一片糊；用得好則建立層次、距離與敘事氛圍。關鍵：正確分類、節制輸入、控制濁度。
:::

## 🎯 本節你會收穫
- 🧪 理解 Insert（直接處理） vs Aux Send（共享空間）差異
- 🏠 室內 / 室外 / 大廳 Reverb 分類與建立策略
- 🎚️ 各類聲音（腳步 / 環境 / 特效）Send 比例判斷原則
- 🧼 避免低頻濁化與長尾覆蓋的控管手段
- 🧩 Reverb 疊加與混音層次協調技巧

## 🧠 Insert vs Aux（複習）
| 類型 | 位置 | 適合 | 範例 |
| ---- | ---- | ---- | ---- |
| Insert | 個別聲音路徑上 | 特殊專屬處理 | 過載失真、特效濾波 |
| Aux Send | 發送到共享 Bus | 同空間感統一 | 房間 / 大廳 / 戶外空氣感 |

原則：空間一致性 → 用 Aux；獨特造型 → 用 Insert。

## 🏠 室內 / 室外風格策略
| 情境 | Reverb 風格 | 設計重點 |
| ---- | ----------- | -------- |
| 小房間 | 短 Early + 中等尾巴 | 250–600ms Decay，避免過度拖尾 |
| 大廳 | 豐富 Early + 長尾 | 1.8–3.5s Decay，控制低頻 |
| 室外 | 幾乎無長尾 | 使用早期反射模擬空氣散射 |

## 🧱 建立多個 Reverb Aux
推薦最小集合：
- `Reverb_Room`
- `Reverb_Hall`
- `Reverb_Outdoor_Air`（可選，僅輕微存在感）

避免為每個場景造一個專屬 Reverb（維護地獄）。

## 🎚️ 套用與比例（初始參考）
| 類型 | Send (Wet %) | 說明 |
| ---- | ------------ | ---- |
| 腳步 | 5–15% | 太高會浮誇不貼地 |
| 環境 Loop | 15–30% | 建立空氣層次 |
| 魔法 / 長特效 | 20–40% | 依場景氛圍調 | 
| UI | 0–5% | 通常保持清晰近場 |

比例只是起點：實際聽混音上下文做微調。

## 🧼 濁度控制技巧
| 問題 | 現象 | 解法 |
| ---- | ---- | ---- |
| 糊成一片 | 中低頻堆疊 | Return 上 EQ：削 200Hz 以下（視情況） |
| 尾巴拖太長 | 聲音佔據空間 | 縮短 Decay / 增加 Damping |
| 主體不貼近 | Reverb 過濕 | 降 Send 或加 Pre-delay 強調直達聲 |
| Layer 疊加爆衝 | 多聲同送高比例 | 分層：主體高、背景低；或限制最大同類 Send |

可加動態 Duck（Reverb Return 被主體直達聲 Sidechain 輕壓）。

## 🧪 測試流程
1. Solo 單一聲音調整至「剛好感覺有空間但不分心」
2. 多聲同播 → 聽是否混成一團；必要時降低背景 Send
3. 切換室內 / 室外場景 → 確保室外殘響不突兀拖尾
4. 關閉全部 Reverb 對照 → 確認加 Reverb 的實質價值

## 🧯 常見錯誤
| 問題 | 原因 | 修正 |
| ---- | ---- | ---- |
| 所有聲都像在大教堂 | 預設直接用 Hall | 拆分 Room / Hall 並分類 Send |
| 低頻轟 | 未過濾 Return | EQ 高通 + 適度低頻壓縮 |
| 主體變遠 | Send 過高 + 無 Pre-delay | 降 Send + 加 10–25ms Pre-delay |
| Loop 污濁 | 尾巴覆蓋起音 | 縮短 Decay 或多段動態處理 |
