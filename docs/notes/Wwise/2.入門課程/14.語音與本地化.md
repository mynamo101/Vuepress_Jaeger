::: tip 🌍 語音系統 = 內容量爆炸 + 高錯誤風險
VO 與本地化是專案後期最容易失控的一塊：命名不一致、語系漏行、字幕不同步。建立規範與檢查表，才能避免災難式回溯。
:::

## 🎯 本節你會收穫
- 📦 認識 VO 與一般 SFX 的流程與維護差異
- 🗂️ 規範的多語資料夾 / 命名格式設計
- 🧪 多語測試與回歸檢查流程
- 🧯 常見落坑（遺漏 / 對應錯誤 / 音量不一致）修正策略
- 🧩 事件設計：隨機 vs 精準對應（字幕 / 劇情）

## 一、VO 的特性
- 量大、迭代頻繁、常後期才補齊
- 需要文本（Subtitle）同步
- 本地化易出現遺漏 / 對應錯誤

## 二、資料夾與命名建議
```
Originals/Vo/zh-TW/
Originals/Vo/en-US/
Originals/Vo/ja-JP/
```
檔名：`<角色>_<語意>_<索引>.wav` 例：`NPCMerchant_Greeting_01.wav`

## 三、語音事件設計
| 策略              | 說明                    |
| ----------------- | ----------------------- |
| 單 Event 多變體   | 一個 Event 下隨機問候語 | 減少程式端 ID 數量
| 分 Event 精準控制 | 劇情關鍵台詞            | 需對應字幕與演出

## 四、語系切換（概念）
遊戲端設定當前語系（Locale），Wwise 自動選對應語系的媒體；若缺檔 → 回退到預設（Fallback）。

## 五、測試流程
1. 在 Project 設定中啟用目標語系（Languages）
2. 為同一個聲音對應多語版本
3. 重新生成 SoundBank（語系差異需重新打包）
4. 在 Authoring 調整測試語系播放

## 六、常見問題
| 問題         | 原因                | 解法                       |
| ------------ | ------------------- | -------------------------- |
| 語系缺一兩行 | 檔名不一致          | 嚴格套公式命名             |
| 字幕不對齊   | 文字時長估錯        | 用表格對照錄音實際長度     |
| 錄音音量落差 | 錄製環境 / 距離不一 | Basic Normalize + 動態處理 |

## 七、語言管理的完整操作

### 新增語言
1. **進入語言設定**：在 Wwise 中，點擊 `Project > Languages`。
2. **新增語言**：
   - 點擊 `Add` 按鈕，選擇需要的語言（如 `en-US`、`zh-TW`）。
   - 為每個語言指定名稱和代碼。
3. **保存設定**：點擊 `OK`，語言將被添加到專案中。

### 刪除語言
1. **進入語言設定**：同樣進入 `Project > Languages`。
2. **選擇語言**：選中需要刪除的語言。
3. **刪除語言**：點擊 `Remove` 按鈕，確認刪除。
4. **清理資產**：刪除語言後，需手動清理相關的音檔與 SoundBank。

### 設定預設語言
1. **進入語言設定**：在 `Project > Languages` 中。
2. **選擇預設語言**：在語言列表中，右鍵點擊目標語言，選擇 `Set as Default`。
3. **保存設定**：點擊 `OK`。

### 語言屬性設置（物件層級）
1. **選擇物件**：在 `Project Explorer` 中，選擇需要設置語言的音效物件。
2. **設置語言屬性**：在右側 `Property Editor` 中，找到 `Language` 屬性，選擇對應語言。
3. **保存更改**：確保語言屬性正確後，保存專案。

### SoundBank 生成語言選擇
1. **進入 SoundBank 設定**：在 `Project Explorer > SoundBanks` 中，選擇目標 SoundBank。
2. **選擇語言**：在 SoundBank 的 `Languages` 標籤中，勾選需要生成的語言。
3. **生成 SoundBank**：點擊 `Generate`，生成包含指定語言的 SoundBank。

### 語言切換技術細節
1. **遊戲端設置語言**：
   - 在遊戲程式中，通過 API 設置當前語言（如 `SetCurrentLanguage("zh-TW")`）。
2. **Wwise 自動選擇媒體**：
   - Wwise 根據當前語言自動選擇對應的音檔。
   - 若缺少對應語言的音檔，將回退到預設語言（Fallback）。

### 語言刪除後的資產清理
1. **檢查未使用的音檔**：刪除語言後，檢查 `Originals` 資料夾中是否有未使用的音檔。
2. **清理 SoundBank**：重新生成 SoundBank，移除已刪除語言的相關資產。

### 最佳實踐與常見錯誤
- **最佳實踐**：
  - 為每個語言建立清晰的資料夾結構（如 `Originals/Vo/en-US/`）。
  - 定期檢查語言與音檔的一致性。
- **常見錯誤**：
  - 語言未啟用導致匯入失敗：確認在 `Project > Languages` 中啟用了目標語言。
  - SoundBank 未包含語言：檢查 SoundBank 的 `Languages` 設定是否正確。
