::: tip 告別機器人音效
想像一下，如果你每次走路的腳步聲都完全一樣，是不是會很奇怪？人耳對重複極度敏感，完全相同的聲音重複三次就會感覺「假」。Random Container 就是用最小成本讓聲音活起來的魔法道具！
:::

- 🛠️ 建立 Random Container 的完整操作流程
- ⚖️ Weight（權重）與 No Repeat 設定技巧
- 👣 腳步與環境細節的實際應用案例

## 🧠 為什麼需要隨機變化？

### 人耳的「重複偵測器」
人類的聽覺系統進化出了極強的重複辨識能力：
- **3次重複** = 開始感覺機械
- **5次重複** = 明顯覺得假
- **10次重複** = 完全受不了

**生活例子**：
- 🔄 老式電話鈴聲：完全重複 → 感覺冰冷
- 🌊 海浪聲：永不重複 → 感覺自然舒適
- 🦅 鳥叫聲：有變化但保持特徵 → Random Container 的目標

## 🛠️ 建立 Random Container 完整指南

### 基本建立步驟
1. **定位**：Actor-Mixer Hierarchy → 選擇合適的父節點
2. **新增**：右鍵 → New Child → Random Container
3. **命名**：例如 `Footstep_Variations`
4. **填充素材**：拖入 4~8 個相關音效檔案
5. **測試**：連續播放多次聽差異

### 🎵 實作練習：腳步聲變化
```
Footstep_Variations (Random Container)
├── 👣 footstep_01.wav (主要音色)
├── 👣 footstep_02.wav (稍重)
├── 👣 footstep_03.wav (稍輕)
├── 👣 footstep_04.wav (更清脆)
└── 👣 footstep_05.wav (略悶)
```

## ⚖️ Weight（權重）系統深入

### 權重的威力
Weight 決定每個素材被抽到的機率，不是平均分配。

| 🎯 策略     | 權重設定 | 🎵 聽感效果           |
| ------------ | -------- | ---------------------- |
| **平均分配** | 1:1:1:1  | 完全隨機，無主體音色   |
| **主體突出** | 5:1:1:1  | 主要音色為主，偶有變化 |
| **分層變化** | 3:2:2:1  | 常見、偶見、稀有三層次 |

### 實際使用時機
- **主體 + 變化**：日常腳步聲（主要音色佔 60%，變化佔 40%）
- **稀有彩蛋**：特殊材質偶爾出現特別聲響
- **情緒漸變**：不同權重營造不同氛圍

## 🚫 No Repeat 設定技巧

### Avoid Repeat 功能
- **基本功能**：避免連續抽到相同樣本
- **History Depth**：記住最近 N 次的選擇，避免重複

| 設定              | 適用情境     | 注意事項             |
| ----------------- | ------------ | -------------------- |
| Avoid Repeat (1)  | 一般腳步聲   | 防止連續兩次相同     |
| History Depth (3) | 對話語音變化 | 記住最近3次選擇      |
| 無限制            | 環境稀有效果 | 可能連續重複，需檢視 |

## 📝 應用案例分析

### 🚶‍♂️ 腳步聲系統
```
策略：5~8 個素材，權重適中偏重，History Depth = 2
目標：保持角色特徵 + 避免機械感
```

### 🍃 葉片摩擦環境音
```
策略：輕/中/重 + 權重偏輕音，偶發重擦聲彩蛋
權重：5:3:1（輕:中:重）
```

### 🔘 UI 提示音
```
策略：2~3 個細微差異，提升耐聽度
權重：均等或略有偏重主音色
```

## ⚠️ 常見錯誤與解決方案

| 🚫 問題             | 🔍 原因         | ✅ 解法                              |
| -------------------- | ---------------- | ------------------------------------ |
| **聽起來還是重複**   | 素材差異過小     | 改變起音/長度/頻率重心，不只調 Pitch |
| **某聲音出現太頻繁** | 權重未調整       | 手動調 Weight 或增加 History         |
| **音色不統一**       | 素材風格差異過大 | 重新錄製或後製統一處理               |
| **音量跳動**         | 各素材音量差異大 | 先做音量 normalize，再進 Wwise       |

### 🎛️ Pitch Random 使用警告
```
❌ 過度調整：±6 半音以上 → 聽起來很假
✅ 適度調整：±1~2 半音 → 自然變化
💡 最佳實踐：依賴素材本身差異，Pitch 僅作微調
```

## 🧪 測試與驗證流程

### 快速測試法
1. **連續播放 20 次**：聽是否有明顯重複感
2. **單獨聽每個素材**：確認風格一致性
3. **調整權重**：根據聽感微調比例
4. **情境測試**：在實際遊戲場景中驗證
