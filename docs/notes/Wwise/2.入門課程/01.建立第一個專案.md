## 🚀 第一步：安裝與啟動 Wwise

### 下載與安裝
1. 前往 [Audiokinetic 官網](https://www.audiokinetic.com/) 註冊帳號
2. 下載 Wwise Launcher（就像 Steam 但專門給 Wwise 用）
3. 透過 Launcher 安裝需要的版本

::: tip 版本選擇小訣竅
如果你是個人學習：選最新穩定版（Latest Release）
如果要與團隊協作：先問程式同事用哪個版本，保持一致避免後續麻煩
:::

**為什麼用 Launcher？**
- 可以同時安裝多個版本（不同專案可能需要不同版本）
- 自動管理插件與更新
- 提供專案範本與學習資源

## 📁 建立你的第一個 Wwise 專案

### 創建步驟
1. **啟動 Wwise**：Launcher → Wwise 標籤 → Launch Wwise
2. **新建專案**：File → New Project...
3. **命名規劃**：例如 `MyFirstProject` 或 `GameAudio_Learning`
4. **選擇位置**：建議放在容易找到的地方（例如桌面或專門的工作資料夾）
5. **插件設定**：初學階段保持預設即可，不要被眾多選項嚇到

::: warning 命名小提醒
專案名稱建議用英文，避免中文字符在某些系統上造成路徑問題
:::

### 🗂️ 專案資料夾結構解密
建立完成後，Wwise 會自動產生這些資料夾：

```
MyFirstProject/
├── 📂 Originals/          # 你的「素材倉庫」
│   ├── SFX/              # 音效檔案
│   ├── Music/            # 音樂檔案  
│   └── Voices/           # 語音檔案
├── 📂 GeneratedSoundBanks/ # 「打包好的成品」
└── 📄 MyFirstProject.wproj # 專案主檔案
```

**生活化比喻**：
- `Originals/` = 你的食材冰箱（原始音檔）
- `GeneratedSoundBanks/` = 做好的便當（給遊戲吃的）
- `.wproj` = 食譜書（記錄怎麼料理）

## 三、介面快速導覽
| 區域                | 作用                      | 記憶法         |
| ------------------- | ------------------------- | -------------- |
| Project Explorer    | 資產/層級/事件樹          | 所有「結構」   |
| Property / Contents | 選取物件的屬性 / 子項     | 「細節與內容」 |
| Transport Control   | 播放、暫停、Profiler 控制 | 媒體控台       |
| Event Viewer        | 測試事件                  | 「呼叫事件」   |
| Soundcaster         | 組合場景模擬              | 微型關卡測試   |

## 🎵 匯入你的第一個音檔

現在來做最有成就感的事：讓 Wwise 發出聲音！

### 實際操作步驟
1. **導航到正確位置**：Project Explorer → Actor-Mixer Hierarchy → Default Work Unit
2. **新增音效物件**：右鍵 → New Child → Sound SFX
3. **命名**：`UI_Click`（或你喂歡的名字）
4. **匯入音檔**：在右側 Contents 或 Property 面板直接拖入 WAV 檔案
5. **測試播放**：按空白鍵或使用 Transport Control 的播放鍵

::: tip 音檔格式小訣竅
- **推薦格式**：WAV 16bit/24bit，44.1kHz 或 48kHz
- **避免使用**：MP3、AAC 等壓縮格式（品質損失）
- **檔案大小**：簡單測試用 1-3 秒的短音效即可
:::

::: warning 常見問題排解
**拖進去沒聲音？**
1. 確認電腦音量沒有靜音
2. 檢查音檔是否損壞（在其他軟體能正常播放）
3. 確認已選中該 Sound 物件再按空白鍵

**音質很糟？**
- 確認原始檔案品質正常
- 檢查是否意外套用了壓縮設定
:::

## 建立你的第一個 Event（遊戲語言的橋樑）

Wwise 中的 Event 就像「遙控器的按鈕」。遊戲程式不會直接說「播放 UI_Click.wav」，而是說「觸發 Play_UI_Click 事件」。

### 創建 Event 步驟
1. **切換到 Events 標籤**：Project Explorer → Events
2. **新增事件**：右鍵 → New Event → Play
3. **選擇目標**：在彈出視窗選擇剛才建立的 `UI_Click`
4. **命名 Event**：`Play_UI_Click`（遵循 Play_ 前綴慣例）

### 測試你的第一個 Event
1. 開啟 **Event Viewer**（通常在畫面底部）
2. 在 Events 清單中雙擊 `Play_UI_Click`
3. 聽到聲音了嗎？恭喜你！🎉

 [!IMPORTANT]
成就解鎖！
你已經完成了 Wwise 的第一個完整循環：素材 → Event → 播放！
這就是 Wwise 的核心工作模式。

## 📦 產出你的第一個 SoundBank

現在要把你的作品「打包」成遊戲可以使用的格式。

### SoundBank 是什麼？
想像你做了一道菜（Wwise 專案），但要打包成便當（SoundBank）才能給別人吃。

### 創建 SoundBank 步驟
1. **切換到 SoundBanks 標籤**：Project Explorer → SoundBanks
2. **新增 SoundBank**：右鍵 → New Child → SoundBank
3. **命名**：`UI_Bank`（或 `My_First_Bank`）
4. **加入 Event**：在 SoundBank 的 Events 頁籤中，勾選 `Play_UI_Click`
5. **產生 SoundBank**：按 F7 或點擊 Generate 鈕鈕

::: tip 💡 生成成功的標誌
在 Log 視窗看到「[SoundBank] Generation completed successfully」就表示成功了！
可以在 `GeneratedSoundBanks/` 資料夾看到相應檔案。
:::

## 💡 常見問題 FAQ

| 🤔 問題           | 🔍 可能原因         | ✨ 解法                                         |
| ------------------ | -------------------- | ----------------------------------------------- |
| 匯入後檔名亂碼     | 原檔命名不規範       | 統一使用英文命名，采用 snake_case 或 PascalCase |
| Event 播放沒聲音   | Event 未正確指向音檔 | 確認在建立 Event 時選擇了正確的 Sound 物件      |
| SoundBank 產生失敗 | 路徑問題或權限不足   | 確認專案路徑沒有中文字符，且有寫入權限          |
