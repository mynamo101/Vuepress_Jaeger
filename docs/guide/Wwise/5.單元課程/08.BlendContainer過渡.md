::: tip 🌀 讓素材「連續滑行」而不是「跳段」
當一個參數（如 RPM、蓄力、風力）是平滑變化且需要不同音色漸進融合時，Blend Container 正是你的動態混音畫布。它不是隨機、也不是條件跳轉，而是『權重隨參數流動』。
:::

## 🧠 何時使用 Blend？
| 需求 | 適合工具 | 說明 |
| ---- | -------- | ---- |
| 多段素材連續融合 | Blend | 依參數權重漸變 |
| 同材質隨機差異 | Random | 無順序關係 |
| 明確條件分支 | Switch | 一次只走一條 |

關鍵判斷：玩家改變速度時，是否希望「上一層殘留一點」？若是 → Blend。

## 🚗 1D RPM 範例實作
素材建議分層：Idle / Low / Mid / High（錄製時確保 Timbre 漸進，避免忽然跳亮或過乾）。

步驟：
1. 建立 Blend Container：`Engine_RPM`
2. 放入四個 Loop（先確認 Loop 點乾淨無爆點）
3. 建 Game Parameter：`EngineRPM`（例：0 ~ 8000）
4. 打開 Blend Editor：為每層設定有效區間並重疊 10~25% 緩衝帶
5. 播放並拖曳參數 → 聽是否平順

### 區間規劃範例（概念）
| Layer | 啟動範圍 | 淡出重疊區 | 設計重點 |
| ----- | -------- | ---------- | -------- |
| Idle  | 0–1200   | 1000–1400  | 保持穩定無顫抖 |
| Low   | 900–3000 | 2600–3200  | 承接 Idle 動感 |
| Mid   | 2800–5200| 4800–5600  | 主體巡航感 |
| High  | 5400–8000| 6000–8000  | 提亮高頻、控制噪訊 |

## 🎚️ 交叉淡化技巧
| 技巧 | 目的 | 提示 |
| ---- | ---- | ---- |
| 適度重疊 | 移除段落感 | 過長重疊會產生相位模糊 |
| Loudness 配平 | RPM 改變不等於音量爆衝 | 以 LUFS / 主觀聽感調整 |
| 高速層 EQ 強化 | 增加速度刺激感 | 避免過度尖銳 5k~8k 適度提升 |
| 低速層暖化 | 提供穩定基底 | 低頻不要疊太厚，避免混濁 |

## 🧭 2D Blend（概念）
當需要兩個參數（例：RPM + 油門開度 / 風速 + 方向）共同決定權重時 → 2D Blend。入門階段可先掌握 1D，避免素材體量暴增。

## 🔍 Debug 與調整流程
1. 設固定 RPM（例：3000）聽該區是否單一層過重（調整重疊）
2. 緩慢由 0 拖到最大：觀察是否出現音量波峰（調整權重曲線）
3. 如聽到「呼吸式波動」：可能是兩層能量頻段互相干涉 → 改 EQ 或縮短重疊
4. 若切換邊界有失真：檢查該層素材起點是否不穩 / 需加淡入

## 🧪 測試建議
| 測試 | 操作 | 通過條件 |
| ---- | ---- | -------- |
| 緩升 | 緩慢拖參數 0 → Max | 無跳層 / 無突增 |
| 快速變化 | 0 ↔ 高速 來回 | 音色瞬換仍平滑（不爆音） |
| 邊界停留 | 卡在重疊交叉 | 不出現明顯拍頻波動 |
| 多聲疊加 | 與環境 / 其他 Loop 同播 | 不互相掩蔽失焦 |

## 🧯 常見錯誤
| 問題 | 原因 | 解法 |
| ---- | ---- | ---- |
| 聲音忽胖忽瘦 | 重疊權重太劇烈 | 調整淡化斜率平滑 |
| 波動 / 相位 | 兩層頻率能量接近 | EQ 拉開頻段 / 縮短交叉 |
| 高速刺耳 | 高頻未控 | 加輕微 Shelf 或 Multiband |
| Idle 聲抖動 | RPM 區間太短 | 擴大 Idle 有效區域 |
