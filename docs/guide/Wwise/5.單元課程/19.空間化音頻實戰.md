### 3D Audio 

>3D Audio在這邊的並不是指我們一般在遊戲中所說的3D音效，而是指Wwise中對於沉浸式的3D Audio Objects的支援，這些物件可以讓我們在3D空間中更真實地模擬聲音的傳播和效果。

在Allow的設定下，我們可以允許該設備中啓用3D音效，這樣音效就可以根據聽眾的位置和方向進行空間化處理，提供更沉浸式的音效體驗。

 - Main Mix Configuration（主混音配置）: 這個選項允許我們選擇主要的混音配置。
    - Binauralization（雙耳化）: 為耳機設定3D音效的音頻輸出格式。
    - Home Theater（家庭劇院）: 為家庭劇院系統設定3D音效的音頻輸出格式。
 - System Audio Objects（系統音頻物件）: 允許系統音頻物件發送到終端設備。
    - Allow（允許）: 啓用系統音頻物件，這樣可以讓我們在3D空間中更真實地模擬聲音的傳播和效果。
    - Minimum Required（最低要求）: 設定終端播放設備最少需要支持的系統音頻物件數量，如果該設備支持這個數量，則3D音效功能將被啓用。如果不支持，則禁用系統音頻物件。

### Audio Objects VS System Audio Objects
| 特性         | 一般的 Audio Objects                                  | System Audio Objects                                                            |
| :----------- | :---------------------------------------------------- | :------------------------------------------------------------------------------ |
| **處理方式** | 由 Wwise 引擎完全處理，最終混音成立體聲或環繞聲格式。 | 帶有元數據（位置、音量等）傳遞給操作系統或硬體，由終端設備進行空間化處理。      |
| **用途**     | 遊戲中常見的 3D 定位音效。                            | 用於支援的平台（如 Dolby Atmos, Windows Sonic）上，實現高精度的沉浸式音效體驗。 |
| **優點**     | 兼容性高，適用於所有平台。                            | 提供更精確、更具沉浸感的物件導向音訊（Object-based Audio）。                    |
| **限制**     | 空間化的精確度受限於最終輸出的聲道數量。              | 依賴終端設備的硬體和平台支援，且可同時處理的物件數量有限。                      |



::: warning 注意事項
假設終端設備支援的System Audio Objects數量為32，當我們設置的Minimum Required為24，雖然符合了要求，但這樣會導致在播放時，如果我們場景中有超過32個System Audio Objects，超過的部分將會被混音到Main Mix，不同的混音處理會導致聲音的體驗效果不佳。

所以建議Minimum Required的數值略高於我們預期的System Audio Objects數量，這樣可以確保在大多數情況下，聲音都能夠被正確處理。
:::
