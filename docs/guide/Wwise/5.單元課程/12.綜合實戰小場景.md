前面學的 Random / Switch / RTPC / Blend / 3D / Reverb / Ducking 現在要實際串起來。這節就是你的「音效系統 MVP」演練場。

## 🎯 本節你會收穫
- 🛠️ 將多種容器與控制手段組成一個行為序列
- 📋 建立可重複驗證的測試表單與紀錄方法
- 🔍 快速定位常見整合失效點（Switch / RTPC / Bank / Duck）
- 🎚️ 初步混音層次分配與優先順序策略


## 一、目標場景敘述
玩家在木製室內房間行走 → 開門到戶外草地 → 加速奔跑 → 低血量 → 撿到任務道具 → 播出 UI 提示 → 遠處引擎車輛駛近（Blend）→ 接到語音通訊（Duck 音樂）。

## 二、所需元素對照
| 系統     | 元素                             | 重點             |
| -------- | -------------------------------- | ---------------- |
| 腳步     | Switch + Random                  | 地面材質切換     |
| 移動速度 | RTPC                             | Pitch / 間隔變化 |
| 環境     | Ambience 室內/室外 + Reverb 切換 | 轉場柔和         |
| 引擎聲   | Blend Container（RPM）           | 平滑進場         |
| 低血量   | 心跳 RTPC                        | 情緒提示         |
| UI 提示  | Event → Bus                      | 清晰不過刺       |
| 語音     | Duck 音樂                        | 焦點轉移         |

## 三、流程腳本（概念）
```
Enter Indoor → Footstep_Wood → Ambience_Indoor + Small Reverb
Open Door → UI_Click + Door Sequence
Exit → Switch Surface=Grass + Ambience_Outdoor + Outdoor Reverb
Sprint → Speed RTPC 上升 → 腳步 Pitch 增 + 間隔縮短
HP 低 → Heartbeat Layer 淡入
Pickup Quest Item → UI_Quest_Accept
Engine Approaches → Engine_RPM Blend 值上升 + 距離衰減改變
Radio Call → Dialogue Event → Music Duck -6dB
```

## 四、驗證表單（示例）
| 項目         | 驗證方法         | 判定標準                         |
| ------------ | ---------------- | -------------------------------- |
| 腳步材質切換 | 手動改 Switch 值 | 音色即時改變無延遲               |
| 速度 RTPC    | 拖動 Speed 參數  | Pitch / 節奏平滑無抖動           |
| 引擎 Blend   | 緩升 RPM         | 無跳層/無波動拍頻                |
| Ducking      | 播 Dialogue      | Music 緩降 40~80ms 內 → 平滑回復 |
| Reverb 轉場  | 室內→室外        | 尾韻不突兀殘留                   |
| 優先級壓力   | 模擬大量聲       | 關鍵互動 / VO 不被丟失           |

## 五、Debug 思路
| 異常        | 可能原因            | 檢查點                  |
| ----------- | ------------------- | ----------------------- |
| 無聲        | SoundBank 未更新    | 重新 Generate           |
| 切換無效    | Switch 未設或值拼錯 | Switch Monitor          |
| RTPC 不動   | 沒更新參數          | Game Parameter Profiler |
| Duck 無作用 | Sidechain 配置錯    | Bus 設定 / Depth 值     |
