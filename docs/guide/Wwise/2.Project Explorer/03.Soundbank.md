::: important 前情提要
所有的素材導入到Wwise之後，遊戲引擎是無法直接讀取Wwise專案中的音效資源的。因此，我們需要將這些音效資源打包成Soundbank，然後遊戲引擎才能夠載入和播放這些音效。
:::

## **Soundbank選項卡介紹**

在 Soundbank 選項卡中的視圖相當簡單，如果要新增 Soundbank，可以直接在Hierarchy上方的圖標點擊新建，或是在Work Unit或是Virtual Folder中透過右鍵選單來建立新的 Soundbank。

![alt text](/Images/Course/Wwise/ProjectExplorer/Tabs/SoundBanks/000_Layout.png)

## **範例演示**

首先，我們可以在`Soundbank`的視圖中來對他的內容進行添加和管理，這點和在F7(Soundbank Layout)中的操作是一樣的。
我們可以參考下面的影片來了解如何將音效資源添加到`Soundbank`中：

::: warning 注意事項
請注意，Soundbank的結構為平行的，也就是說你無法在Soundbank中建立子資料夾來進行分類，或是將Soundbank放置在其他Soundbank中。 
:::
