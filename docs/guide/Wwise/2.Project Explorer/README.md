::: tip 拆解 Project Explorer 的一切
在開始使用 Wwise 之前，了解 Project Explorer 是學習 Wwise 的第一步。Project Explorer 是 Wwise 專案的核心界面，所有的聲音資源、事件、混音設定等都在這裡進行管理和組織。
:::

我們會在接下來的章節中，逐步介紹每個Project Explorer中的重要區塊和元素，當你瞭解了這些基礎知識後，你已經基本學會使用 Wwise 來管理你的遊戲音效專案了！

祝學習順利，開始你的聲音系統築城之旅！
