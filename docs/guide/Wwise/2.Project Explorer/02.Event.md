::: important 關於 Event 選項卡
Wwise 的 Event 選項卡是專門用來管理和編輯事件的區域。在這個區域中，你可以創建、編輯和組織遊戲中的音效事件，這些事件用於觸發音效的播放。Event 選項卡提供了強大的工具，讓你能夠靈活地設計和控制遊戲中的音效行為。
:::


## **Event選項卡介紹**

在事件的選項卡中，雖然Event本身有多種的形態，無論是播放音效、控制音效的行為或是設定邏輯條件等，但大致上可以分為以下兩種主要的Event類型：

### Event - 基本事件

此為Wwise中最基本的事件類型。它能夠針對Audio選項卡中的各種物件進行觸發動作，例如播放、停止、暫停等。是Wwsie和遊戲引擎之間進行互動的主要橋樑。

在`Events`的選項卡中，我們可以在`Work Unit`或是`Virtual Folder`中透過右鍵選單來建立新的`Event`。以下是一些常見的Event類型：

![alt text](/Images/Course/Wwise/ProjectExplorer/Tabs/Events/000_EventType.png)
我們可以看到右鍵選單中箭頭所指的部分，點擊可以直接新建一個空的事件。
也可以透過下方的細分項目來直接建立帶有特定功能的事件。

### Dialogue Event - 對話事件
此為Wwise中負責管理遊戲對話音效的事件類型，透過`Dialogue Event`，我們可以更方便地組織和觸發遊戲中的對話音效。`Dialogue Event`通常與`Sound Voice`做搭配使用。

![alt text](/Images/Course/Wwise/ProjectExplorer/Tabs/Events/001_DialogueEvent.png)
