::: tip 拆解互動音樂的核心
在開始使用 Wwise 之前，了解互動音樂的概念是學習 Wwise 的第一步。互動音樂是 Wwise 專案的核心部分，所有的音樂資源、事件、混音設定等都在這裡進行管理和組織。
:::
