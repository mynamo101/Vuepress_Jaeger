## Wwise 佈局（Layout）介紹

在 Wwise 中，有多種不同的佈局（Layout），每種配置都針對不同的工作流程和需求進行了優化。以下是一些常見的佈局：

### 1. Designer Layout (F5)
![alt text](/Images/Course/Wwise/Layout/F5.png)
Wwise 的預設佈局，專為音效設計師設計。它提供了豐富的工具和視圖，方便用戶進行音效創作、編輯和管理。
這也是我們大多數在編輯音效時會使用的介面。

在界面中，一共分為幾個主要區域：
::: card title="Project Explorer" icon="material-symbols:dashboard-outline"  

在這個區塊下一共分成7個選項卡，分別是:

![alt text](/Images/Course/Wwise/PropertyEditor/000_ExplorerTabs.png)

  - **Audio**：管理所有音效素材，包括音檔的導入、分類與編輯。
  - **Events**：設定觸發音效的事件，讓遊戲或應用程式能夠呼叫特定音效。
  - **SoundBanks**：將事件和音效素材打包，方便在遊戲中載入和管理。
  - **Game Syncs**：管理遊戲參數（如狀態、RTPC、Switch），用於動態控制音效表現。
  - **ShareSets**：建立可重複使用的屬性設定（如效果器、混音器），方便多個物件共用。
  - **Sessions**：儲存和管理工作階段，方便團隊協作或版本回溯。
  - **Queries**：快速查詢和篩選專案中的各類資源，提升管理效率。

![alt text](/Images/Course/Wwise/Intro/006_TransportControl.png)
Transport Control 提供了基本的播放控制功能，讓你可以方便地預聽音效，並調整遊戲參數以測試不同的聲音效果。

#### Play Origins / Converted

![alt text](/Images/Course/Wwise/TransportControl/001_Origins.jpg)

你可能注意到播放按鈕旁邊有一個額外的擴充鈕，點開之後會看到 `Play Origins` 和 `Play Converted` 兩個選項。
而這兩個選項的差異在於：

- **Play Origins**：播放原始音檔，適合在匯入後立即測試音檔是否正確。
  - 當你需要檢查原始音檔的內容時，請勾選此選項。
- **Play Converted**：播放經過 Wwise 轉換後的音檔，適合測試最終效果。
  - 當你對匯入的音檔進行了轉換設定（如壓縮、格式等）後，可以勾選此選項來聆聽最終效果。

### 2. Profiler Layout (F6)
![alt text](/Images/Course/Wwise/Layout/F6.png)
在遊戲測試和調試階段非常有用的佈局，搭配引擎時可以開啓連線並檢測我們的音效在遊戲中的表現，主要用於性能分析和調試。它提供了詳細的性能數據和圖表，幫助用戶識別和解決音效相關的性能問題。
### 3. SoundBank Layout (F7)
![alt text](/Images/Course/Wwise/Layout/F7.png)
這個階段將我們之前所有的事件和素材打包成 SoundBank，也是非常重要並且一定會使用到的界面配置。
### 4. Mixer Layout (F8)
![alt text](/Images/Course/Wwise/Layout/F8.png)
我們會在這個界面進行所有的總線混音工作，並且可以設定各種效果器和參數來調整遊戲中聽到的效果。
### 5. Schematic Layout (F9)
![alt text](/Images/Course/Wwise/Layout/F9.png)
這個配置提供了一個視覺化的節點圖界面，方便用戶以圖形方式設計和管理音效事件和邏輯。
### 6. Audio Objects Profiler Layout (F10)
![alt text](/Images/Course/Wwise/Layout/F10.png)
這個配置專注於音頻對象的性能分析，提供了詳細的音頻對象數據和性能指標，幫助用戶優化音效資源的使用。
### 7. Voice Layout (F11)
![alt text](/Images/Course/Wwise/Layout/F11.png)
這個配置專為語音處理設計，提供了專門的工具和視圖，方便用戶管理和處理語音資源。
### 8. Game Object Profiler Layout (F12)
![alt text](/Images/Course/Wwise/Layout/F12.png)
這個配置專注於遊戲對象的音效性能分析，提供了詳細的遊戲對象數據和性能指標，幫助用戶優化遊戲中的音效表現。
